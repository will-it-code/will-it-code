# Will it code? 🛠️

Every day, one AI dev tool faces one real build challenge — on camera, no
tricks. Either **IT CODED ✅** or **IT FAILED ❌**. Watch the showdowns on
Instagram: [@will.it.code](https://www.instagram.com/will.it.code)

This repo holds every build from the series. Each demo is a single
self-contained HTML file — download it or click it and it just runs. No
build step, no dependencies, no API keys.

## ▶️ Run a demo

No install. Either:
- Open any file in `demos/` directly in your browser, or
- Serve the folder: `python3 -m http.server` and visit `http://localhost:8000/demos/`
