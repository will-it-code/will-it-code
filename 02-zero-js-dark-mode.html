THE CHALLENGE

A dark-mode toggle with ZERO JavaScript.

No script tags. No frameworks. One hidden checkbox, one CSS :checked selector, and CSS variables flip the entire theme. Tap the switch — watch it code.

#theme-toggle:checked ~ .page {
  --bg: #101014; /* 🌙 dark */
  --fg: #f2f0ea;
}
/* one checkbox. pure CSS. that's it. */
